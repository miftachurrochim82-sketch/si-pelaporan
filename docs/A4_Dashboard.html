Tentang Aplikasi

SI-PELAPORAN adalah Sistem Informasi Pelaporan Pegawai di lingkungan Pemerintah Kabupaten Trenggalek. Aplikasi ini digunakan untuk mencatat, mengelola, dan memverifikasi laporan pelaksanaan tugas pegawai, dengan data pegawai, jabatan, dan unit kerja yang terintegrasi langsung (read-only) dari SIMPEG. Login menggunakan akun resmi melalui SI-Platform (Single Sign-On) — tidak ada password terpisah di aplikasi ini.

Fitur Utama

Dashboard

Statistik jumlah laporan per jenis, grafik distribusi pegawai, status jabatan, dan 5 laporan terbaru.

Pelaporan

Buat, ubah, dan hapus laporan kerja (rutin, insidental, khusus, pengawasan). Dilengkapi verifikasi admin serta ekspor Excel/PDF.

Analisa Pelaporan

Analisa otomatis per tahun/bulan: ringkasan eksekutif, distribusi, temuan, rekomendasi — dapat diunduh sebagai PDF.

Profil Saya

Data kepegawaian Anda dari SIMPEG (read-only) + pemeliharaan kontak: alamat, nomor HP, dan email.

Master Data

Referensi SIMPEG read-only: pegawai, jabatan, dan unit kerja — dengan pencarian, paginasi, dan ekspor.

Pengaturan Admin

Parameter sistem (mis. daftar jenis laporan) yang dapat diubah administrator tanpa deploy ulang.

Alur Status Laporan

menunggu disetujui

Setiap laporan baru berstatus menunggu dan diverifikasi oleh administrator menjadi salah satu dari:

  • Disetujui — laporan valid dan diterima.
  • Perlu Revisi — perbaiki sesuai catatan verifikator (muncul di bawah judul laporan), lalu simpan kembali.
  • Ditolak — laporan tidak dapat diterima; alasan tertera pada catatan verifikator.

Cara Membuat Laporan

  1. 1Buka menu Pelaporan, klik tombol Buat Laporan.
  2. 2Lengkapi form: pegawai (terkunci ke akun Anda), tanggal, jenis laporan, judul, dan uraian lengkap.
  3. 3Klik Simpan Pelaporan — laporan masuk dengan status menunggu.
  4. 4Tunggu verifikasi administrator. Bila berstatus revisi, baca catatannya, ubah laporan, lalu simpan kembali.
  5. 5Gunakan tombol Excel/PDF di halaman Pelaporan untuk mengunduh rekap data.

Tanya Jawab

Mengapa laporan saya masih berstatus "menunggu"?

Laporan menunggu pemeriksaan administrator. Status hanya dapat diubah melalui proses verifikasi — bukan oleh pelapor.

Mengapa saya hanya bisa mengelola laporan milik sendiri?

Sistem melindungi kepemilikan data: pegawai hanya dapat mengubah/menghapus laporannya sendiri. Administrator dapat melihat seluruh laporan untuk keperluan verifikasi.

Data pegawai/jabatan/unit saya salah — bagaimana memperbaikinya?

Data tersebut berasal dari SIMPEG (read-only). Hubungi pengelola kepegawaian/BIKSDM untuk perbaikan di sistem sumber.

Sesi saya berakhir / diminta login ulang terus?

Sesi mengikuti tiket SSO SI-Platform. Masuk kembali melalui tombol "Masuk via SI-Platform"; jika berulang, hubungi administrator aplikasi.
